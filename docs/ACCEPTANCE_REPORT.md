## 1. 项目概述

| 字段 | 说明 |
|------|------|
| 项目名称 | 低空经济企业IP情报咨询服务 |
| 架构模式 | TraeWork + IMA 双轨架构 |
| 交付日期 | 2026-08-17 |
| 数据截止日期 | 2026-08-17 |

本项目面向低空经济领域，构建了一套从数据采集、实体识别、企业画像、知识图谱构建到竞争分析的全链路情报服务系统。系统采用 **TraeWork + IMA 双轨架构**：TraeWork 负责自动化数据采集、NER 实体提取、知识图谱构建与竞争分析等数据处理流水线；IMA 负责将结构化情报导出为知识库内容，支撑企业级智能问答与情报检索。

系统当前已覆盖 eVTOL 整机、通航运营、无人机整机、军工航空四大细分赛道，监测 8 家重点企业，累计采集情报记录 490 条，构建知识图谱节点 88 个、边 318 条，导出 IMA 知识库文件 16 个。

## 6. 已知限制

| 序号 | 限制项 | 影响范围 | 缓解措施 |
|------|--------|----------|----------|
| 1 | HanLP 在本地环境可能因 transformers 版本不兼容而降级为 spaCy 单引擎 | NER 实体提取精度可能下降；人物实体识别能力减弱 | 本地开发时锁定 transformers 版本；生产环境（GitHub Actions）已预装兼容版本 |
| 2 | GitHub Actions 每次运行最长 45 分钟 | 单次采集量受限；超时可能导致流水线中断 | 已优化采集间隔与并发；超时自动重试机制（max_retries: 3） |
| 3 | 数据源依赖外部网站可用性 | 外部网站宕机或改版时采集失败；RSS 源变更导致数据中断 | 多源冗余配置（18 路数据源）；错误数监控（当前 errors: 0）；定期检查数据源健康状态 |
| 4 | NER 人物实体识别精度依赖 HanLP 模型质量 | 人物实体识别可能遗漏或误判；当前仅识别 1 个人物实体（存在 "Tiltrotor" 误判为人物的情况） | 后续添加行业人物词典；优化消歧规则覆盖技术术语误判 |
